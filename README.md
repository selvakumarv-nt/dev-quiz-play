# Web Dev Quiz Master

"Act as a senior frontend engineer and web development tutor. Help me build a 2nd-year college computer science project: an Interactive Quiz Application using Semantic HTML5, CSS3 (Flexbox/Grid), and Vanilla JavaScript.

Please provide the complete, fully functional code files:

index.html: With a header, footer, a landing screen, a quiz arena screen (including a progress bar), and a score results summary screen. Use semantic tags.

style.css: A clean, modern UI with a dark/light color palette, smooth transition animations for screen states, and fully responsive layouts for mobile and desktop.

script.js: Complete logic handling an array of 5 sample web dev questions, choice selection, score tracking, dynamic screen swapping (toggling hidden classes), and a 'restart' feature. Keep the code clean, modular, and well-commented for an academic submission."
